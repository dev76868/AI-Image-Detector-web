# Real Or Fake — AI Image Detector Website

Static marketing and legal website for the **Real Or Fake** iOS app.

## Pages

- `index.html` — responsive product landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use

## Assets

App icon and product screenshots are stored as optimized WebP files in `assets/`.

## Hosting

No build step is required. The repository can be served directly from the root with GitHub Pages or another static host.
